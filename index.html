Formulir Data Laporan PLP

Naskah rapi, format sesuai kampus, sitasi anti pusing. Isi bagian demi bagian secara berurutan; bagian berikutnya terbuka setelah bagian sebelumnya terisi. Isianmu tersimpan otomatis, jadi bisa dilanjutkan kapan saja. Di bagian terakhir, tekan “Buat ringkasan”, lalu kirim ke WhatsApp DAMNEDIT.

Formulir ini memuat NIP/NUPTK. Data tidak disimpan di server mana pun. Draf isianmu hanya tersimpan di browser perangkat ini (hapus lewat tombol di bagian terakhir, terutama jika memakai perangkat bersama). Data dienkripsi di perangkatmu sebelum dikirim. Data baru terkirim ketika kamu menekan tombol kirim di WhatsApp, dan hanya ke admin DAMNEDIT.
1. Identitas mahasiswa

Kolom bertanda * wajib diisi.

2. Pejabat dan nomor identitas

Data Dekan dan Ka. Bag. PLP dan PPL sudah terisi otomatis dan tidak dapat diubah. Untuk pejabat lain, nama wajib diisi dan nomor boleh dikosongkan bila belum ada (akan ditandai [ ... ]). Gelar yang salah tulis dibetulkan otomatis oleh Claude.

3. Masa PLP

Tanggal boleh ditulis bebas. Hari dan tanggal akan disesuaikan dengan kalender oleh Claude.

4. Profil sekolah

Kolom bertanda * wajib. Data profil sekolah tidak dikarang oleh Claude, jadi isi dengan data asli. Kolom lain boleh dikosongkan.

5. Jadwal dan materi mengajar (bahan RPM)

Satu kotak per pertemuan. Hari/tanggal dan materi wajib. Kolom lain boleh dikosongkan; nanti dilengkapi secara wajar oleh Claude. Isi sesuai kejadian bila ada.

6. Lembar observasi (Lampiran 1 dan 2)

Pilih minimal satu jawaban di tiap lampiran. Yang dibiarkan “—” akan dilengkapi secara wajar oleh Claude.
